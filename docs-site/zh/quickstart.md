# 第一张工单

在熟悉的项目里试一张只读单：让工人找到测试、告诉你怎么运行，不改文件。从项目根目录开始，先登录一种工人。

## 1. 登记项目

```sh
cc-bro init
```

按提示填允许的工人标识；如果填了多个，再选一个作为默认值。只填一个也可以。下面的命令会用项目默认工人，两种后端都能照做。

## 2. 给工单起名并派出

```sh
cc-bro say test-map "找到测试放在哪里，告诉我怎么运行其中一个。不要改文件。" --bg --json
```

`--bg` 让命令先交回回执，工人继续运行。记下回执里的 `name` 和 `turn`。首次使用 `test-map` 时是第 1 轮；同名再次派单会沿用已有会话。

## 3. 等待、检查、收单

```sh
cc-bro wait test-map 1
cc-bro show test-map
cc-bro done test-map
```

将 `1` 换成回执中的实际轮次。先看回复，再决定是否执行 `done`。需要补充就对同名工人再 `say`，然后等新回执中的轮次。

## 在 Claude Code 里试一次

在项目对话中输入 `/cc-bro`，交代：“找一下测试放在哪里，不要改文件。”技能会派单并在后台等待。打开[看板](board.md)可以查看进度。
