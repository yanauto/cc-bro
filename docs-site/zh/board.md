# 看板

打开本机看板，可以看到哪些单在排队、工人改了什么，以及哪些结果还等你验收。

```sh
cc-bro ui
cc-bro ui --no-open
```

第一条命令打开浏览器；第二条只打印当前本机地址。选中项目即可查看它的工单。

## 看工单走到哪一步

- **排队（Queued）：** 等待空闲名额。有空位时，另一名字的工单可以并行。
- **进行中（Working）：** 工人正在执行。打开详情可看最近步骤、所用工人和模型，以及可用的分支和文件改动。
- **待验收（Review）：** 工人已交回结果，等经理检查。进这一列不代表有另一个工人审过；需要独立审查时，用 `review --by` 派审查单。
- **已完成（Done）：** 经理已用 `cc-bro done NAME` 收单。

## 核对依据

详情里可以读最终回复和时间线，查看插话结果以及写单、审查单的关联。输入缓存命中率取工人最近一次上报的用量；缺少数据表示未知，不是实测为零。改动文件清单可以作为检查工作目录的入口，不表示文件已经提交。

在终端用 `cc-bro ls` 列出当前项目工单，`cc-bro watch` 持续看活动，`cc-bro show NAME --all` 查看对话历史。


从页头打开**配置**，管理[花名册](roster.md)、[项目设置](settings.md)和[自定义模板](custom-cli.md)。工单详情显示所选档位、能力等级、用户备注与规矩提醒。
